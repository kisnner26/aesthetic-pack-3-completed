# Aesthetic pack 3 (completed) 🌸

Pastel-pink pixel-art cursor set for Windows.

## Credits

The original cursor set, **Aesthetic pack <3 [ Not completed ]**, was created by **✧ • Skyler • ✧** and released to the **public domain**:
<http://www.rw-designer.com/cursor-set/aesthetic-pack-3-not-completed>

All original cursors (normal, link, help, text, working, busy, unavailable, handwriting) are theirs, unmodified.

## What I added

The original pack was incomplete (8 of 17 roles). I drew the 9 missing cursors in the same style (32×32, same palette, small heart):

vertical / horizontal / both diagonal resize, move, precision (cross), alternate (up arrow), person, location.

See `preview/new-cursors.png`.

## Download (easiest)

**[Aesthetic-Pack-3-Installer.exe](https://github.com/kisnner26/aesthetic-pack-3-completed/releases/latest/download/Aesthetic-Pack-3-Installer.exe)** — one-click installer, no admin needed. It backs up your current cursors first; run it with `/restore` to go back. Windows SmartScreen may warn because it is unsigned: *More info → Run anyway*.

All releases: <https://github.com/kisnner26/aesthetic-pack-3-completed/releases>

## Manual install

1. Download / clone this repo.
2. Right-click `cursors/install.inf` → **Install**.
3. Settings → Bluetooth & devices → Mouse → Additional mouse settings → Pointers → pick **Aesthetic pack 3**.

`cursors/aesthetic-pack-3.crs` is the same set for RealWorld Cursor Editor.
